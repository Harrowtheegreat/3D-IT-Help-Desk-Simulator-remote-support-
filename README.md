# 3D-IT-Help-Desk-Simulator-remote-support-
A 3D IT help desk simulator where you practice real-world support tickets, like printer troubleshooting, remote software installs and Wi-Fi issues

An interactive 3D simulator for practicing real-world IT help desk tickets. You act as the help desk tech at a school. You read tickets, talk to users, investigate the problem and fix it, while a coach explains each step in simple terms.
